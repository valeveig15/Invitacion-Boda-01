# Invitación Botánica · Martina & Federico · V6

Versión con marco botánico completo y nueva iconografía vectorial animada.

## Qué cambió
- Ceremonia: capilla vectorial con halo y respiración suave.
- Fiesta: copas de champán que chocan suavemente.
- Regalo: caja que abre la tapa y deja salir destellos.
- Instagram: logo lineal con ondas pulsantes.
- Dress code: percha/atuendo con balanceo sutil.
- Confirmación: sobre con tilde animada.
- Canciones: notas musicales flotantes.
- Info útil: pin de ubicación con pequeño rebote.

## Publicación
El archivo `index.html` es autocontenido para los recursos locales: incluye estilos, JavaScript, marco botánico y música. Las fotografías y Google Fonts siguen cargándose desde Internet.
Para GitHub Pages, reemplazá el `index.html` de la raíz del repositorio por este archivo.
